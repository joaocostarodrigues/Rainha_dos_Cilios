# Localizador de lojas

A página `map.html` usa `map.css` e `map.js`.

As unidades cadastradas ficam no objeto `stores` de `map.js`. Para adicionar uma loja, inclua nome, telefone e endereço no estado correspondente. Os totais, os botões de acesso rápido e a lista são atualizados automaticamente.

O mapa do Brasil é um SVG incorporado em `map.html` e funciona sem conexão com a internet. Cada estado pode ser selecionado no mapa pelo clique, toque ou teclado. O seletor de estados oferece a mesma navegação.

O desenho do mapa também fica salvo em `brazil.inline.svg`. A licença dos dados geográficos está em `MAP_DATA_LICENSE.txt`.
